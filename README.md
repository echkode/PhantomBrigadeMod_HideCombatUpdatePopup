# HideCombatUpdatePopup

A library mod for [Phantom Brigade](https://braceyourselfgames.com/phantom-brigade/) to hide the update popup in combat.

It is compatible with game release version **2.1.0**. It works with both the Steam and Epic installs of the game. All library mods are fragile and susceptible to breakage whenever a new version is released.

Some events in combat will trigger a popup to appear in the upper right corner of the screen. This mod adds a toggle to the game options that can be turned off to prevent that popup from showing during combat. The popup will continue to appear in the province and mobile base screens regardless of the setting of the toggle.
